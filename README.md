# 合成大恒星 v2

移动端优先的单画面恒星合成游戏，无第三方运行时依赖。只保留游戏、得分、下一颗恒星、暂停、重来、天体查看和选项；原实验室、图谱、侧栏、事件记录与独立说明界面已删除。

## 本地运行

Node.js 22+：`npm run dev`，打开 http://127.0.0.1:4173 。部署仅需 `dist/`。

测试：`npm test`。

鼠标移动后点击投放；触屏拖动后松手投放。左右方向键或 A/D 移动，空格投放，P 暂停。查看模式可点击天体查看质量和元素分层。选项包含音效、剖面、光线偏折、更多粒子与减弱动态。切到后台自动暂停。

## 这版调整

- B、O 和更高质量恒星的坍缩等待时间由 27/18/7 秒延长为 **135/90/35 秒**。
- 超新星粒子、冷却碎屑与余辉持续 **14 秒**，为原 2.8 秒的五倍。冲击前沿约2.4秒扩散至最大作用半径，碰到外圈恒星时才给予冲量。
- 黑洞单目标质量转移公式为 **(0.72 + 0.075 × 黑洞质量) / 20 M☉/s**，严格为原速率的1/20。通关后的多目标质量转移也使用此比例。
- 胜利阈值 **40 × 50 = 2,000 M☉**。结尾经数亿年的时间跳跃表现约10⁶ M☉的星系中心。
- 中子星不会因吸积变成黑洞。保留质量上限2.3 M☉，剩余燃料记作喷流排出，仍持续产生周期X射线暴。双中子星并合仍形成黑洞。
- 得分按合并质量计算，通关时间奖励为 `round(6000 / (1 + 秒数 / 180))`。v2的最高分与旧版分开存储。

## 像素材质和物理

恒星由有颜色、径向分层及对流运动的受约束材质像素构成，按12Hz更新离屏像素贴图，主画面使用最近邻采样。原平滑球体和装饰引力光圈已移除。主序分层以H/He和输运区为主，最后25秒才显示C/O、Si与Fe等临终分层。

脱落物质从供体面向吸积天体的一侧产生，带有切向速度。自由粒子具有独立位置、速度、寿命及温度色阶，经历引力加速、内盘耗散、壁面反弹和冷却；进入黑洞内边界后消失。超新星持续喷出具有径向初速度的碎屑，炸毁的邻星也释放像素材质。中子星产生双向粒子喷流与X射线暴。

这借鉴[Noita的材质像素思路](https://noitagame.com/)，并非其完整逐像素多相流/化学引擎；天体的质量和碰撞仍由圆形刚体模拟负责，自由像素是低开销的物质示踪。

## 引力与光线偏折

1. **天体引力：**紧致天体和其余天体采用Plummer软化的牛顿平方反比场，`a = G M r / (r²+ε²)^(3/2)`。成对施加相反动量，在近距离统一限制加速度，避免奇点和数值爆炸。普通恒星之间的额外自引力省略，保留容器中的下落玩法。
2. **物质示踪：**像素粒子采用同一个软化引力函数；每颗粒子选择锁定的吸积源或最近的紧致天体作为主导场，避免粒子全体两两计算。近盘加入耗散，让有角动量的物质逐渐落入。
3. **背景光线：**使用点质量薄透镜方程 `θ± = (β ± sqrt(β² + 4θE²))/2`，绘制向外偏移的主像、奇偶反转的次像和近对齐的爱因斯坦弧。使用最强主导透镜，θE与天体半径及示意距离绑定。中子星透镜半径比黑洞小。
4. **吸积盘光线：**使用低成本的解析投影，把背面盘像弯到黑洞阴影上方及下方，并以像素表示近光子环；配有示意多普勒亮度差。这是Schwarzschild外观近似，并非完整广义相对论光线追踪。参考[NASA黑洞结构](https://science.nasa.gov/universe/black-holes/anatomy/)。
5. **引力波：**并合产生向外传播的波包，背景星点横向伸长、垂直方向压缩，表现四极形变；不会作为爆炸冲击推动天体。显示幅度为可见性放大。参考[LIGO引力波说明](https://ligo.org/gravitational-wave-science/)。

## 性能

- 自由粒子上限：高画质2,600，省电画质1,100。
- 恒星材质上限：高画质22,000，省电画质10,000；所有恒星公平分配预算，离屏更新12Hz。
- 高画质DPR最多1.5，省电模式最多1；手机默认省电画质。
- 背景星点高画质242、省电145。没有全屏光线步进、GPU图像回读、模糊后处理和粒子N体求解。
- 固定60Hz物理，单帧追赶不超过0.1秒。支持减少动态与完整暂停。

## 科学近似

光谱合成顺序M→K→G→F→A→B→O遵循温度顺序，0.25/0.5/1/2/4/8/16 M☉是保证合成守恒的游戏阶位，不严格对应真实光谱质量边界。8/25 M☉是按初始质量区分中子星/黑洞的教学近似，真实结局还受金属丰度、核心结构和质量损失影响。

低质量星300秒变白矮星、白矮星吸积到1.4 M☉触发Ia、NS上限喷流与并合必成BH、爆炸清屏、X射线暴给予整颗恒星动量、放大的透镜尺寸/引力波均为玩法模型。不同型不能合成及一次吸积一颗也是游戏规则。尺寸、距离与时间并非统一真实比例。科学细节保存在源码说明中，避免占用游戏界面。

## 文件

`dist/simulation.js`：质量、碰撞、演化、传播冲击波、引力和得分。

`dist/renderer.js`：像素材质、示踪粒子、透镜、引力波、结局。

`dist/app.js` / `index.html` / `style.css`：输入、单画面移动界面和选项。

`tests/`：质量守恒、倍率、NS保留、延迟冲击、透镜方程、指针投放、暂停、界面与粒子预算等回归测试。

Windows打包使用Git自带Bash，并设置 `TAR_OPTIONS=--force-local`，让tar将盘符识别为本地路径。
