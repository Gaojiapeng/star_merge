# 合成大恒星 · Stellar Forge

一个无运行时依赖的 Canvas 2D 恒星合成网页游戏。界面为中文，采用暗色像素粒子、恒星切面、吸积盘、引力透镜与时空涟漪视觉效果。

## 运行

需要 Node.js 22 或更新版本。在本目录执行：

```sh
npm run dev
```

打开 http://127.0.0.1:4173 。静态部署只需要 `dist/`；不依赖在线字体、图片、音频或第三方 JavaScript。

```sh
npm test
```

## 操作

- 鼠标移动落点，点击释放；触屏按住调整落点，松手释放。
- 左右方向键或 A / D 移动，空格释放，P 暂停。
- 切换“观测”后点击天体，查看质量、内部元素分层和剩余演化时间。
- “物理实验室”提供六个预设场景，替换当前棋盘，不写入正式最高分。
- 设置中可开关剖面、减少粒子、减弱动态；音效为浏览器合成，可自行开启。
- 最高分与设置只存储在当前浏览器本地。后台页面自动暂停正式演化。

## 已实现机制

1. 相同光谱类型接触合成，M → K → G → F → A → B → O；不同类型仅碰撞，O + O 继续增加质量。
2. 每颗恒星显示类型、质量和内部切面，观测面板显示结构、元素与演化信息。
3. ≥8 M☉ 的恒星短时间核心坍缩；8–25 M☉ 留下中子星，≥25 M☉ 留下黑洞。
4. 超新星摧毁近处普通恒星，向较远天体施加径向冲量。
5. 黑洞一次锁定一颗普通恒星吸积，供体逐渐缩小，吸积物质以弯曲粒子流显示。
6. 黑洞合并与较弱的中子星合并都触发引力波动画。
7. 中子星吸积引发周期 X 射线热核暴，向周围天体施加小幅冲量；质量超过2.3 M☉或双中子星合并形成黑洞。
8. <8 M☉ 恒星年龄达到300秒成为白矮星；白矮星吸积达到1.4 M☉发生Ia超新星，自身消失并产生冲量。
9. 单颗黑洞达到40 M☉胜利，解锁多目标吸积；镜头拉远，经明确标注的宇宙时间跳跃，展示星系中心。
10. 根据合并质量产生积分；通关奖励 `round(6000 / (1 + 通关秒数 / 180))`，越快越高。
11. 顶部堆积越界持续3秒失败；实验场景禁用溢出失败。

## 科学设定

这是一款以天体物理为灵感的合成游戏，不是恒星演化数值模拟器。

- 为保证合成质量守恒，七阶质量设为0.25、0.5、1、2、4、8、16 M☉；与真实光谱质量关系不严格对应。温度参考真实光谱数量级。
- 8 / 25 M☉ 的遗骸分界按初始质量作教学近似；真实结局还取决于金属丰度、核心结构、风损失与双星演化。
- 普通主序星显示H/He及能量输运层。重元素洋葱层只在临近核心坍缩时出现。层厚仅为示意，不代表元素精确质量丰度。
- 低质量星5分钟寿命、同型才能合并、单目标吸积、爆炸清屏、X射线暴推动恒星、可见引力波均为游戏规则或视觉夸张。
- 红矮星真实寿命远超当前宇宙年龄；并非所有低质量星遗骸都是可以触发Ia的碳氧白矮星。本作将这些路径统一简化。
- 中子星2.3 M☉阈值及并合必成黑洞是简化；真实结局依赖状态方程、旋转和总质量。
- 40 M☉只是游戏的种子黑洞通关阈值。结局通过亿万年时间跳跃表现~10⁶ M☉星系中心黑洞。

## 文件

- `dist/simulation.js`：固定步长物理、质量转移、演化、得分、实验场景。`PHYSICS`集中定义质量阈值。
- `dist/renderer.js`：Canvas渲染、粒子与结局，不改变模拟状态。
- `dist/app.js`：输入、交互面板、音效、本地纪录与60Hz模拟循环。
- `dist/index.html` / `dist/style.css`：响应式界面和科学说明。
- `tests/`：Node原生测试，覆盖主要天体物理路径。

当前平衡偏宽松，主要挑战是用更少时间完成通关。可修改 `winningMass`、投放分布、吸积速度、坍缩倒计时与冲击范围继续调整。

## 验证范围

已完成核心机制自动测试、多种子随机投放压力测试，以及六种实验场景的渲染接口检查。当前环境的浏览器访问策略阻止了本地页面视觉检查，因此未声称通过真实浏览器截图验收或真机触屏验收。
